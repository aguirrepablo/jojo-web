# Instagram Workspace: JOJO (`@jojo.ar`)

Espacio de trabajo para la planificación, generación de contenido, prompts visuales y gestión automatizada de la cuenta de Instagram de JOJO a través de herramientas de IA y el **Model Context Protocol (MCP)**.

---

## 📁 Estructura del Directorio

```
instagram-work/
├── README.md                      # Esta guía general
├── estrategia.md                  # Pilares de contenido, tono de marca, formatos y hashtags
├── calendario_publicaciones.md    # Planificador editorial semanal/mensual con estado de posts
├── mcp_setup.md                   # Guía de conexión y configuración del MCP Server de Instagram
├── posts/                         # Borradores completos de publicaciones (copy, slides, prompts)
│   ├── post_01_software_a_medida.md
│   ├── post_02_ia_en_produccion.md
│   └── post_03_microservicios_vs_monolito.md
└── assets/                        # Recursos visuales y prompts de generación
```

## 🚀 Flujo de Trabajo

1. **Ideación & Calendario:** Seleccionar el tema del post según los pilares en [estrategia.md](file:///C:/Users/peagu/Workspace/jojo/jojo-web/instagram-work/estrategia.md) y programarlo en [calendario_publicaciones.md](file:///C:/Users/peagu/Workspace/jojo/jojo-web/instagram-work/calendario_publicaciones.md).
2. **Generación de Contenido:** Redactar el post en `posts/` (Hook, slides de carrusel / guion de Reel, caption, hashtags y CTA).
3. **Generación Visual:** Crear assets visuales o mockups usando la identidad de JOJO (Fondo oscuro `#171717`, acento coral `#F24444`, tipografía técnica y limpia).
4. **Publicación / Automatización vía MCP:** Conectar y ejecutar las acciones del servidor MCP de Instagram detalladas en [mcp_setup.md](file:///C:/Users/peagu/Workspace/jojo/jojo-web/instagram-work/mcp_setup.md) para publicar, programar o monitorear métricas.
